# Chapitre 1 : Les notes longues

## La ronde et la pause
Consigne : Compte 1 - 2 - 3 - 4. Dis « ron-de lon-gue », chuchote « chut » pendant la pause.
Mesure : 4/4

- r | r | p
  = ron-de_lon-gue | ron-de_lon-gue | (chut)
- r | p | r | p
  p | r | r | p
- r | r | p | r
  p | r | p | r
- p | r | r | r
  r | p | p | r

## La blanche
Consigne : Dis « blan-che » : la blanche dure 2 temps. Frappe sur 1 et sur 3.
Mesure : 4/4

- b b | b b | b b | b b
  = blan-che blan-che | blan-che blan-che | blan-che blan-che | blan-che blan-che
- r | b b | r | b b
  b b | r | b b | p
- r | p | b b | b b
- b b | b b | r | p
  p | b b | r | b b
- b b | r | p | r
  r | b b | p | b b

## La demi-pause
Consigne : La demi-pause se tait 2 temps, comme une blanche. Elle est posée sur la ligne.
Mesure : 4/4

- b dp | b dp | dp b
  = blan-che (chut) | blan-che (chut) | (chut) blan-che
- b b | b dp | b b | dp b
  r | b dp | r | dp b
- dp b | b b | b dp | r
- b dp | p | dp b | r
  b b | dp b | p | b dp
- r | dp b | b dp | p
  dp b | b b | r | b dp

## Révision : notes longues et silences
Consigne : Frappe les notes. Pendant les silences, lève les bras et compte dans ta tête.
Mesure : 4/4

- r | b b | p | b dp
  b dp | r | dp b | p
- b b | p | r | b b
  dp b | b dp | b b | r
- r | dp b | p | b b
  p | b b | b dp | r
- b dp | dp b | r | p
  b b | r | dp b | r

# Chapitre 2 : Le temps

## La noire
Consigne : Compte 1 - 2 - 3 - 4 : dis « noir » sur chaque noire, elle dure 1 temps.
Mesure : 4/4

- n n n n | n n n n | n n n n
  = noir noir noir noir | noir noir noir noir | noir noir noir noir
- n n b | b n n | r | n n n n
  b b | n n b | p | n n n n
- n b n | n n b | b dp | r
- r | n n n n | b n n | dp b
  n n n n | n b n | p | b b
- b n n | r | n n b | n n n n
  dp n n | n b n | b n n | r

## Le soupir
Consigne : Le soupir se tait 1 temps, comme une noire : chuchote « chut ».
Mesure : 4/4

- n n n s | s n n n | n s n s
  = noir noir noir (chut) | (chut) noir noir noir | noir (chut) noir (chut)
- s n n n | b n s | n n s n | b dp
  n s n s | s n b | n n s s | p
- b n s | s n n n | dp n s | r
- s n s n | n n b | n s s n | b b
  n s n n | b s n | s n n s | r
- n n n n | n s n s | s n b | dp b
  n s b | n n s n | b n s | p

## Révision : noires, blanches et silences
Consigne : Regarde bien chaque signe : note ou silence ? Combien de temps ?
Mesure : 4/4

- n n b | b s n | n n n s | r
  b dp | n s n n | r | n n b
- n s b | p | n n n n | b dp
  r | n n s n | dp n n | b b
- n n n s | b n s | dp b | r
  b n n | s n b | p | n n n n
- n s n s | r | b dp | n n b
  dp n n | n n b | n s n s | r

# Chapitre 3 : Les mesures à 2 et 3 temps

## La mesure à 3 temps
Consigne : En 3/4, compte 1 - 2 - 3 : trois temps dans chaque mesure.
Mesure : 3/4

- n n n | n n n | n s n
  = 1 2 3 | 1 2 3 | 1 (2) 3
- b n | n b | n n n | b n
  n n n | b n | s n n | n b
- n b | b n | n n n | p
- b n | n n n | dp n | n b
  n s n | b n | n n n | s b
- n n n | b n | s n n | n b

## La blanche pointée
Consigne : La blanche pointée dure 3 temps, toute la mesure : dis « blan-che lon-gue ».
Mesure : 3/4

- b. | n n n | b.
  = blan-che_lon-gue | noir noir noir | blan-che_lon-gue
- b n | b. | n b | b.
  n n n | b. | b n | p
- n b | n n n | b. | b.
- b. | b s | n n n | b.
  s n n | b. | n s n | b.
- b n | n n n | dp n | b.
  n b | s b | n n n | p

## La mesure à 2 temps
Consigne : En 2/4, compte 1 - 2 : deux temps par mesure. La pause dure toute la mesure.
Mesure : 2/4

- n n | n s | s n | n n
  = 1 2 | 1 (2) | (1) 2 | 1 2
- n n | b | n n | b | n n | b
- b | n s | n n | p | n n | b
  s n | n n | b | s n | n s | b
- n n | n s | b | p | n n | b
- b | s n | n n | b | p | n n
  n s | b | n n | s n | b | b
- n n | b | s n | n s | n n | b
  p | n n | b | n n | n s | b

## Révision : 2, 3 ou 4 temps
Consigne : Regarde le chiffrage avant de commencer : 2, 3 ou 4 temps par mesure ?
Mesure : 4/4

- n n b | r | b n n | b dp
- 3/4 : b n | n n n | b. | s n n
        n b | b. | n s n | b.
- 2/4 : n n | b | s n | n n | p | b
- r | n s n n | b b | p
  n n n n | b. n | n s b | r
- 3/4 : n n n | b s | n b | p
- 2/4 : b | n n | s n | b | n n | b

# Chapitre 4 : Les croches

## La croche
Consigne : Compte « 1 et 2 et 3 et 4 et ». Deux croches dans un temps : dis « deux-croch ».
Mesure : 4/4

- c c c c c c c c | n n n n
  = deux- croch deux- croch deux- croch deux- croch | noir noir noir noir
- c c n n n | n c c n n | b c c n | r
  n n c c n | c c n b | n n n c c | b b
- c c c c b | n c c n n | r | n n c c n
- b c c c c | c c n n n | n n b | c c c c b
  n c c n n | b n c c | c c c c n n | r
- c c n c c n | r | n n c c n | b b
  b n c c | c c c c n n | n c c b | r

## Croches avec tout ce que tu connais
Consigne : Croches, noires, blanches, rondes... et les silences ! Attention au chiffrage.
Mesure : 4/4

- c c s n n | b c c s | c c c c dp | r
- 3/4 : c c n n | b c c | c c c c n | b.
        n c c n | s c c n | c c c c c c | p
- dp c c n | s c c b | n n c c s | p
  c c n b | c c c c s n | dp n c c | r
- 2/4 : c c n | c c c c | n s | c c n | s c c | b
- 3/4 : b c c | n c c n | c c s n | b.
        s n n | c c c c n | n s c c | p

## Le demi-soupir
Consigne : Le demi-soupir se tait pendant une croche : chuchote « chut », tout court.
Mesure : 4/4

- n c ds n n | c ds c ds n n
  = noir ta (chut) noir noir | ta (chut) ta (chut) noir noir
- n n s n | n s n s | c c s c c n
  c ds n n n | n c ds n n | c ds c ds n n
- c c s c ds n | n c ds s n | c c c c s n
- s n c c n | c ds c c s n | n n c ds s
  c ds c ds n n | n n s c c | c ds c c n s
- n n c c s | c c c ds n s | s c c c ds n
  c c n s n | s n c c n | c c c c n s

## Croches et tous les silences
Consigne : Pause, demi-pause, soupir, demi-soupir : chuchote « chut » et continue de compter.
Mesure : 4/4

- c c n s n | b dp | c ds c c n n | p
  c ds c c b | n s dp | c c c c n s | r
- b c c n | dp c c n | n c ds s n | p
  c c s b | c ds n dp | p | c c c c b
- n n c c s | b c ds n | dp c c c c | r
  c ds c ds b | p | n s c c n | dp b
- dp n c c | c c n b | s n c ds n | p
  b s n | c c c c dp | c ds n b | r

## Le contretemps
Consigne : Demi-soupir puis croche : « chut - ta ». La croche arrive juste après le temps.
Mesure : 4/4

- ds c ds c n n | n ds c n n
  = (chut) ta (chut) ta noir noir | noir (chut) ta noir noir
- n ds c n n | ds c ds c b | n n ds c n | r
- ds c n ds c n | b ds c n | n ds c c c n | p
  c c ds c n n | ds c ds c ds c n | n n ds c s
- 3/4 : ds c n n | n ds c n | ds c ds c n | b.
        n n ds c | s ds c n | ds c n s | p
- 2/4 : ds c n | n ds c | ds c ds c | b | n n | ds c n

# Chapitre 5 : La noire pointée et la syncope

## La noire pointée
Consigne : Noire pointée puis croche : dis « noi-re croch' ». Ensemble, ça fait 2 temps.
Mesure : 4/4

- n. c n n | n. c n n | n. c b
  = noi-re croch' noir noir | noi-re croch' noir noir | noi-re croch' blan-che
- n n n. c | b n. c | n. c n. c | r
  n. c c c n | n n n. c | b n. c | p
- n. c b | c c n. c n | n n b | n. c n s
- n. c s n | dp n. c | n. c c c n | r
  b n. c | n n. c n | n. c n n | b dp
- n. c n. c | s n b | c c c c n. c | r
  n n n. c | b s n | n. c b | p

## La syncope
Consigne : Croche - noire - croche : dis « syn-co-pe ». La noire commence entre deux temps.
Mesure : 4/4

- c n c n n | c n c b | r
  = syn- co- pe noir noir | syn- co- pe blan-che | ron-de_lon-gue
- n n c n c | c n c c c n | b c n c | r
- c n c s n | n c n c n | c c c n c n | p
  b c n c | n s c n c | c n c b | r
- 3/4 : c n c n | n c n c | c n c n | b.
        s c n c | c n c s | b n | p
- 2/4 : c n c | n n | c n c | b | n n | c n c

## La noire pointée en 3/4 et en 2/4
Consigne : Regarde le chiffrage : en 2/4, « noi-re croch' » remplit toute la mesure.

- 3/4 : n. c n | n. c n | b n | b.
        n n n | n. c n | n. c s | b.
- 2/4 : n. c | n n | n. c | b | n. c | b

- 3/4 : n. c c c | b n | n. c s | p
- n. c n. c | b. n | n. c b | r
- 2/4 : n. c | s n | c c n | n. c | p | b
- 3/4 : b. | n. c n | c c n. c | b.

## Révision : noire pointée et syncope

# Chapitre 6 : Le triolet

## Le triolet
Consigne : Trois croches dans un temps : « tri-o-let ». Le petit 3 te le montre.
Mesure : 4/4

- t t t n t t t n | t t t t t t n n
  = tri- o- let noir tri- o- let noir | tri- o- let tri- o- let noir noir
- n n t t t n | t t t n n n | t t t t t t b
  b t t t n | n t t t t t t n | r
- t t t c c t t t c c | n n t t t n | t t t t t t b
- c c t t t n n | t t t c c b | t t t s t t t s
  n s t t t n | c c t t t c c n | b dp
- t t t t t t n n | n c c t t t n | r

  t t t c c c c n | n n t t t n | r
- 3/4 : t t t c c n | s c c t t t | b.
